# Amazon Ads Codex Operator v0.5.0

**Codex Evergreen / native archive-sealed source release.**

v0.5.0 keeps the v0.4 sealed execution model and broad in-envelope AI autonomy, then removes system `PATH` Codex updates from the production trust decision. Production uses an Owner-pinned, SHA-256 verified ACTIVE Codex runtime; new versions are candidate snapshots that must satisfy the stable capability contract before explicit atomic promotion. The previous ACTIVE remains available for rollback.

This release also adds a repo-scoped Codex plugin marketplace, daily latest-Codex compatibility CI, immutable green-main auto sealing, and a single-`main` branch hygiene workflow.

Source sealing does not certify a particular Amazon Ads account. Real OAuth, live MCP schema binding, controlled writes and recovery drills remain required by `docs/ARCHIVE_ACCEPTANCE.md` for each production deployment.
